# CodeAlpha_FAQChatbot

An interactive, automated desktop support agent designed to resolve common internship and workspace queries. It utilizes custom Rule-Based Natural Language Processing (NLP) string tokenization logic to match user intents with a predefined knowledge base. Developed as part of my **Artificial Intelligence Internship** at **CodeAlpha**.

## 🚀 Features
- **Instant Intent Matching:** Automatically processes queries and scores sentence structural overlaps to isolate correct answers.
- **Predefined Knowledge Base:** Packed with automated solutions concerning CodeAlpha internship durations, requirements, task metrics, and certification guidelines.
- **Beautiful Chat UI:** Built with custom Tkinter grid canvas modules mimicking real-world instant messaging platforms.
- **Dynamic Auto-Scrolling:** Automatically jumps focus to the bottom of the log when new text packets arrive.

## 🛠️ Tech Stack
- **Language:** Python 3
- **GUI Layout:** Tkinter (Built-in)
- **Algorithm Architecture:** Custom String Tokenizer and Keyword Overlap Parser

## 📦 Setup & Execution

1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Launch the application (Requires zero external library installations!):
   ```bash
   python chatbot.py
   ```
